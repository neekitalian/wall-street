# Decision Cheatsheet

## Start Here

| Situation | First artifact | Decisive question |
|---|---|---|
| Dealer product | Sales-trader-client loop | Who owns the risk after execution? |
| Bond portfolio | Return decomposition | Is yield compensation for duration, credit, liquidity, or optionality? |
| LBO | Sources and uses | Which assumption creates the equity return? |
| Acquisition auction | Bid-quality matrix | What is risk-adjusted closing value? |
| Sensitive information | Provenance chain | What duty or restriction travels with it? |
| Hedge fund | Strategy fingerprint | What hidden factor or tail pays for the return? |
| Relative-value trade | Liquidity spiral stress | Can funding survive widening before convergence? |
| Contrarian trade | Thesis-to-instrument chain | How exactly does being right produce cash? |
| Quant strategy | Data-to-execution pipeline | Does the edge survive out of sample and after costs? |
| Distressed company | Entity-claim map | Which assets support which claim? |
| Restructuring | BATNA-by-class | What can each group force, block, or wait out? |
| Macro risk | Transmission map | What is the causal path into cash flow and price? |

## Fast Decision Rules

- If a seller is enthusiastic, inspect inventory and compensation before inferring investment merit.
- If leverage is required to make returns attractive, stress haircuts, correlation, and liquidation simultaneously.
- If a thesis has no catalyst, budget indefinite carry or reject it.
- If an LBO return depends mainly on a higher exit multiple, treat the case as market timing.
- If two bids differ in certainty, compare expected closing value, delay, and failed-deal downside.
- If information is valuable and nonpublic, stop and establish provenance and duties before trading.
- If net exposure is low, still measure gross, factor, liquidity, and tail exposure.
- If a backtest is excellent, count researcher choices and demand genuine out-of-sample evidence.
- If a company has many entities, never allocate recovery from consolidated numbers alone.
- If litigation drives a restructuring demand, convert headline damages into probability, time, cost, and collectability.
- If a global risk is prominent, do not trade it until the transmission and instrument basis are explicit.

## Failure Smells

| Smell | Likely hidden problem |
|---|---|
| Smooth returns plus leverage | Short volatility, illiquidity, or stale marks |
| Many "diverse" convergence trades | One shared funding/liquidity factor |
| High yield with simple story | Credit, optionality, or liquidity omitted |
| Deal model needs perfect refinancing | Path insolvency |
| Management strongly favors one bidder | Employment, rollover, or fee conflict |
| Derivative payoff described without definitions | Contract-thesis basis risk |
| Strategy scales without decay | Costs, crowding, or capacity ignored |
| Parent creditor claims operating assets | Structural subordination or missing guarantee |
| Settlement compared only by percentage recovery | Time, litigation, control, and certainty ignored |
